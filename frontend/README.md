# Netrasaathi Frontend

Accessible Next.js frontend for **Netrasaathi**, built with Next.js App Router, TypeScript, Tailwind CSS, and the browser Web Speech API.

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Run type checking
npx tsc --noEmit

# 4. Run linting
npm run lint

# 5. Run automated tests
npm test

# 6. Build for production
npm run build
```

## Environment Configuration

Configure `.env.local`:
```bash
NEXT_PUBLIC_API_BASE_URL=http://localhost:8000
NEXT_PUBLIC_USE_MOCK=false
```
